# Rail-Hosted Chrome and Inline Notices

Revise the Tab Shell chrome from [ADR-0007](./0007-tab-shell-ui.md) and [ADR-0008](./0008-four-tab-shell-and-single-toggle-transport.md): the identity moves **into** the shell. The **Brand Unit** (icon mark, `DEMUXIFY` display wordmark, pulsing status dot, mono tagline) lives at the head of the **Tab Rail** at every breakpoint — the page-level header element dies outright, so the page opens straight into rail + stage with the `sticky top-0 z-30` rail `<nav>` pinning the frame. Below `md` the brand row and the four Tab chips are one **merged sticky block**: the Brand Unit is the first child of the rail grid (`col-span-4`, row 1) above the four chips on the nav's base `grid grid-cols-4`, pinned as a single unit while scrolling; the tagline is desktop-rail-only (`hidden md:block`), keeping the reduced mobile lockup near 108px, and the identity statement "Client-Side Stem Separation" survives on mobile as copy in the System Tab panel body. The toast **DOM surface** dies (`src/components/Toast.tsx` and its rail placement are deleted): gated-Tab taps become a silent no-op answered by the grayscaled chip's bare reason line, and export outcomes announce themselves **inline in the Export Tab** — a mono micro line with the peach status pip for success, the same line in tan for cancel, and the existing `role="alert"` card for failure. The Separate Tab's coral **hero band** and its "in-browser · nothing uploaded" state copy are deleted at both breakpoints along with their stylesheet rules, and the **footer goes flat**: one tan hairline (`border-grz-600/40`, the token the rail chips and System band already use) replaces the 2px warn rule over the deep-red gradient slab, keeping its two centered micro lines and the `w-full` width constraint. Visual language is unchanged: same Grizzlython ramp, Bold typography, and tokens — zero palette changes, deep red surviving only for alert semantics.

## Considered Options

- Keep a full-width desktop header above the rail (rejected: it competes with the rail for the frame and pushes the stage down; branding belonged to the frame already carrying the tools).
- Keep the mobile header strip and rail strip as two blocks with only one pinned (rejected: brand and navigation scrolled as separate units, one disappearing mid-scroll).
- Keep rail-mounted toast notices stacked at the rail end (rejected: notices hover over the tools at every breakpoint; refusals duplicated the chip's own reason line) — inline notices at the acting surface answer instead.
- Keep a gated-Tab refusal notice (rejected: the grayscaled chip with its reason line is already the whole answer; a second copy is noise).
- Re-tune the Separate Tab title zone or restyle the footer via a new design pass (rejected: removals and re-homes only; the run-7 title-zone rhythm and the grz-02 width fix stay exactly as ported).
- Design this increment in OpenDesign (rejected: no new visual language — every part already exists in the artifacts and components, so this follows the removals-and-re-home exception recorded in [ADR-0008](./0008-four-tab-shell-and-single-toggle-transport.md) and the grz-11/13/15/18 addendum; new visual language would resume the OpenDesign mandate).

## Hard to Reverse

The deleted surfaces (`Header.tsx`, `Toast.tsx`, the hero-strip element and its CSS pair, the gradient footer) are gone from the composition, not hidden; reintroducing any of them means new DOM, new placement contracts inside the merged sticky block, and new test seams that the chrome contract tests now actively forbid (`queryByRole("header")` must be null, zero toast testids, zero hero-strip class hits). The single responsive mechanism — Brand Unit as first child of the rail `<nav>`, `col-span-4` on the nav's own grid flipping `md:flex md:flex-col` — is the only thing keeping mobile and desktop chrome in sync; a second "desktop" breakpoint reintroduces the drift this increment removed.

## Supersede

Partially supersedes [ADR-0007](./0007-tab-shell-ui.md): the Tab Shell frame, four-Tab gating, shared Master Waveform spine, Bold visual identity, and the port-through-React process stay; its page-level header branding, rail-bottom toast notices, the Separate Tab hero band (grz-03 hero rule), and the gradient footer rule claims no longer apply. It supersedes no behavior from [ADR-0008](./0008-four-tab-shell-and-single-toggle-transport.md) but reuses that ADR's precedent for skipping an OpenDesign run. The glossary names the **Brand Unit** (with "header", "top bar", "sidebar" retired as _Avoid_ terms) as hosted by the **Tab Shell** — see `GLOSSARY.md`.
