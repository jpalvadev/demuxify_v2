1. Deepen the Export Engine & Collapse the Export Monolith

Strong in-process
src/components/ExportDialog.tsx · src/lib/customMixdown.ts · src/lib/bundleZip.ts · src/lib/wavEncoder.ts · src/lib/mp3Encoder.ts · src/App.tsx
Problem

Export orchestration—offline time-stretching, anti-clipping gain calculation, click-track synthesis, multi-track WAV/MP3 encoding, and ZIP bundle creation—is tangled inside an 1137-line UI component, forcing tests to drive the DOM to verify audio algorithms.

Solution

Extract a deep Export Engine module that coordinates offline rendering, encoding, and packaging behind a single command interface, shrinking the view into a thin ExportTab.

Architectural Wins
  • Locality: all encoding logic lives together
  • Tests hit engine without DOM
  • Leverage: one interface handles all formats
  • Export Tab becomes pure view
  • Retires historical "Dialog" name debt
  • Eliminates exportDialogState bridge in App
ADR Alignment: Honors ADR-0004 (anti-clipping protection) and ADR-0007 / ADR-0014 (Tab Shell UI), formally retiring the historical "Dialog" naming in GLOSSARY.md for an inline Export Tab.

2. Deepen Session Management behind an In-Memory Session Core

4. Unify the Canvas Waveform Rendering Engine

Worth exploring in-process
src/components/MasterWaveform.tsx · src/components/StemStrip.tsx · src/lib/waveformPeaks.ts
Problem

MasterWaveform and StemStrip duplicate low-level canvas rendering logic—retina pixel ratio scaling, ResizeObserver management, peak bucket normalization, and playhead interpolation—across their separate implementations.

Solution

Extract a dedicated headless Waveform Renderer module that manages canvas lifecycle, peak drawing, and playhead animation, reducing both components to thin view containers.

Architectural Wins
  • Locality: rendering math in one module
  • Eliminates duplicate DPI scaling loops
  • Waveform drawing testable without DOM
  • StemStrip and MasterWaveform shrink
  • Guarantees visual consistency across tabs

Worth exploring local-substitutable

Problem

  • Drums vs mix fallback hidden inside
  • Tap calibration tested without UI
  • Direct alignment with GLOSSARY concepts
ADR Alignment: Unifies ADR-0010 (tempo detection) and ADR-0011 (beat grid downbeat/repair derivations) behind one seam.
